# 🚀 AI Engineering — 120 Days

> **120 days of rebuilding my AI foundations, learning from official documentation, implementing concepts from scratch, and documenting the journey publicly.**

Welcome to my **AI Engineering — 120 Days** journey.

I already have familiarity with many concepts in **Artificial Intelligence and Machine Learning**, but knowing the theory and truly understanding how things work are different.

Through this challenge, I am going back to the fundamentals and rebuilding my knowledge systematically — not because every concept is new to me, but because I want to understand each concept more deeply, identify misconceptions, and develop a strong engineering foundation.

My primary learning source throughout this journey is **official documentation**, supported by experiments, implementations, exercises, and projects.

---

## 🎯 Why 120 Days?

AI is a large field.

It is easy to learn libraries, follow tutorials, build a few projects, and still have gaps in fundamental understanding.

Instead of rushing toward advanced topics, I decided to spend **120 focused days** developing a structured foundation for AI Engineering.

The objective is not simply:

> *"Learn as many AI tools as possible."*

The objective is:

> **Understand the concepts → understand the implementation → experiment with them → build with them → explain what I learned.**

---

## 📚 My Learning Philosophy

### 1. Documentation First

Official documentation is my primary reference whenever possible.

Instead of only learning *how to use* a library or framework, I want to understand:

* Why a feature exists
* How it behaves
* What assumptions it makes
* What happens internally
* What common misconceptions surround it
* When it should and should not be used

---

### 2. Fundamentals Before Abstractions

Modern AI frameworks provide powerful abstractions.

But abstractions become much more useful when the fundamentals underneath them are clear.

So this journey starts from:

**Python → Mathematics → NumPy → Data → Machine Learning → Deep Learning → Transformers → LLMs → RAG → Agents → MLOps**

and gradually moves toward advanced AI Engineering.

---

### 3. Clearing Misconceptions

One of the biggest goals of this challenge is identifying things that I *thought* I understood but did not understand completely.

For each major concept, I try to ask:

**What did I previously believe?**

**What actually happens?**

**Why does it work that way?**

**What experiment can prove it?**

These small corrections compound into stronger engineering intuition.

---

### 4. Learn by Experimenting

Reading alone is not enough.

For important concepts, I create small experiments to observe their actual behavior.

My typical learning cycle is:

**Concept → Mental Model → Documentation → Experiment → Prediction → Execution → Interpretation → Misconception Check**

This helps convert theoretical knowledge into practical understanding.
